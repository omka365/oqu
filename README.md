# Oqu — умный конструктор подготовки

Oqu превращает PDF, фотографию конспекта или обычный текст в учебный набор: карточки, мини-тест и тренировку. Приложение рассчитано на iOS и Android.

## Что уже работает

- Expo / React Native приложение на TypeScript.
- Современный мобильный интерфейс для школьников и студентов.
- Загрузка PDF и выбор фотографии из галереи.
- Ручная вставка текста.
- Демо-набор без API-ключа.
- Интерактивные карточки с переворотом и прогрессом.
- Тест с четырьмя вариантами, объяснением и итоговым счётом.
- Серверный API Fastify для облачной генерации через OpenAI.
- Общие Zod-контракты между мобильным приложением и сервером.

## Структура

```text
apps/mobile       мобильное приложение Expo
apps/server       API генерации учебных наборов
packages/contracts общие TypeScript/Zod-схемы
```

## Требования

- Node.js 20 или новее.
- npm 10 или новее.
- Проект настроен под Expo SDK 58 и совместим с Expo Go SDK 58.
- Для проверки приложения: Expo Go на Android или iPhone.
- Для настоящей генерации: ключ OpenAI на сервере. Для телефона также нужен адрес компьютера в локальной сети в `EXPO_PUBLIC_API_URL`.

Установка зависимостей из корня проекта:

```bash
npm install
```

В проекте используются локальные пакеты через `file:`, поэтому установка через npm поддерживается напрямую.

## Запуск демо

В первом окне PowerShell из корня:

```bash
npm run mobile
```

Команда запускает Expo именно из папки `apps/mobile`. Если запускаешь вручную, сначала выполни `cd apps\\mobile`.

Если после старой неудачной установки осталась папка `node_modules`, удали её и файл `package-lock.json`, затем снова выполни `npm install`.

Открой QR-код в Expo Go. Если QR-код не работает, запусти:

```bash
npx expo start --tunnel --workspace @oqu/mobile
```

Демо-набор «Эпоха Возрождения» доступен сразу на главном экране. Можно открыть карточки, переворачивать их и пройти тест.

## Подключение ИИ

1. Создай файл `apps/server/.env` на основе `.env.example` и добавь `OPENAI_API_KEY`.
2. Запусти сервер командой `npm run server`.
3. Узнай IPv4 компьютера командой `ipconfig`.
4. Перед запуском мобильного приложения задай адрес сервера:

```cmd
set EXPO_PUBLIC_API_URL=http://192.168.1.25:8787
```

Замени `192.168.1.25` на IPv4 своего компьютера. Телефон и компьютер должны быть в одной Wi-Fi сети. Ключ OpenAI в мобильное приложение не добавляется.

## Запуск сервера

Скопируй пример переменных окружения:

```powershell
Copy-Item apps/server/.env.example apps/server/.env
```

Для работы без реального ИИ ключ оставь пустым: приложение всё равно запускается в демо-режиме. Для генерации добавь ключ в `apps/server/.env`:

```env
OPENAI_API_KEY=ваш_ключ
OPENAI_BASE_URL=https://адрес-провайдера/v1
OPENAI_MODEL=имя-модели-провайдера
PORT=8787
```

Запусти сервер в отдельном окне:

```bash
npm run server
```

Проверка:

```text
http://localhost:8787/health
```

Ключ хранится только на сервере. Не добавляй его в приложение, Git или файл `.env.example`.

## Подключение телефона к локальному API

Телефон и компьютер должны быть в одной Wi-Fi сети. В мобильном приложении адрес API нужно указать как адрес компьютера в сети, например `http://192.168.1.25:8787`, а не `localhost`. IP компьютера можно посмотреть командой `ipconfig` в Windows.

Если Windows Firewall блокирует соединение, разреши Node.js для частной сети. Для теста через интернет можно использовать защищённый туннель, но публичный сервер требует авторизацию и ограничение расходов.

## Отдельное приложение без Expo Go

Для Android APK:

```cmd
npm install -g eas-cli
eas login
cd apps/mobile
eas build --platform android --profile preview
```

После сборки EAS покажет ссылку на APK. Скачай APK на Android и установи его. Для Google Play используй production AAB:

```cmd
eas build --platform android --profile production
```

Для iOS:

```cmd
eas build --platform ios --profile production
```

Для iOS потребуется Apple Developer account. EAS может собрать приложение удалённо, но публикация в App Store всё равно требует учётную запись Apple. Для отдельной сборки API должен быть доступен через HTTPS; адрес `192.168...` подходит только для локальной разработки.

## Проверки

```bash
npm run typecheck
```

На Windows Android удобно проверять через Expo Go. Для iPhone под Windows используй Expo Go; полноценная iOS-сборка через Xcode требует macOS. Облачная генерация требует действующий ключ провайдера и может тарифицироваться.

## Ограничения MVP

- Без регистрации и синхронизации между устройствами.
- Наборы и прогресс пока подготовлены для локального режима; полноценная SQLite-синхронизация — следующий этап.
- Серверный пример принимает PDF и изображения, но для production нужно добавить извлечение текста из PDF, OCR для изображений, авторизацию, постоянное хранилище, лимиты пользователя и удаление временных файлов.
- API без авторизации подходит для локальной разработки и контролируемого теста. Перед публикацией в App Store или Google Play его нужно закрыть авторизацией и защитой расходов.
